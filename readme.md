# SkyFlix

An aviation-focused video platform for enthusiasts.

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Express.js
- PostgreSQL
- Prisma

## Features
- User registration and login
- Video upload and management
- Video search and filtering
- Video watch history
- Video rating and comments
- Video transcoding and streaming
- Channel creation and management
- Channel search and filtering
- Channel about page
- Channel video search and filtering
- Channel video watch history
- Channel video rating and comments
- Channel video transcoding and streaming
- Channel report and moderation

## Installation

1. Clone the repository
2. Install dependencies
3. Create a `.env` file in the root directory and add the following variables:

```
DATABASE_URL=postgresql://user:password@localhost:5432/skyflix
```

4. Run the following commands:

```
npm install
npm run dev
```
